# Skill Refine

Aplicação para criação e gestão de currículos (CV) com temas, preview e exportação em PDF.

- **Frontend**: React + TypeScript (FSD), em `client/`
- **Backend**: Django + DRF + Postgres, em `backend/`
- Subir serviços: `docker compose up -d`; ver `client/README.md` e `backend/README.md` para rodar cada parte.
