# Skill Refine

Monorepo for **Skill Refine**: a resume builder and AI-assisted analysis platform. It contains a **React** frontend (`client/`), a **Django + DRF** backend (`backend/`), and optional **ML** assets under `ml/` (no Markdown docs in-repo; see code and `env.example` files for tooling).

## What is in this repository

| Area | Role |
|------|------|
| `client/` | Web app (React 19, TypeScript, Feature-Sliced Design). |
| `backend/` | REST API, auth, resumes, analysis, dashboard, notifications. |
| `ml/` | Models, training scripts, and datasets (configure via env and scripts). |
